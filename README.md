The World in One Day — Saturday 21 November 2026

A make.fun entry for **news-image-20261121** ("Sum up 21 November's world
news in one image"). The program draws a newspaper front page and writes
it to `/output/entry.png`.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```

Python 3 standard library only — no Pillow, no network, no randomness.
Every run writes the exact same bytes (1024x1024 PNG, about 19 KB).
